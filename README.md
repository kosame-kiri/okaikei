# おかいけい

イベント会場（即売会・物販ブース）向けの簡易レジ。ブラウザだけで動き、一度開けばオフラインでも使える。

- グッズ（名前・値段・画像）を登録 → レジ画面にボタンが並ぶ
- ボタンをタップで数量 +1・合計に加算
- 会計でお預かり金額を入力するとお釣りを表示（不足時は警告）
- 履歴: 日付ごとの売上合計・グッズ別販売数・会計の取消・CSV 書き出し

データ（グッズ・画像・履歴）はその端末のブラウザ内（localStorage）にだけ保存される。サーバーには送らない。

## 使い方

- **iPad / スマホ**: 公開 URL を Safari で開き、共有 →「ホーム画面に追加」。以後はホーム画面のアイコンから起動する（オフラインでも起動する）。
  - iOS ではホーム画面のアプリと Safari のタブで保存データが別になる。グッズ登録はホーム画面から開いたアプリの中で行う。
- **PC**: `index.html` をブラウザで直接開いても使える（この場合はファイルを開いたブラウザに保存される）。
- 別の端末へ移すとき・念のための控え: グッズ登録画面の「控えを保存（JSON）」「控えを読み込む」。

## ファイル

- `index.html` — アプリ本体（単一ファイル、外部依存なし）
- `sw.js` — オフライン用 Service Worker
- `manifest.webmanifest`, `icons/` — ホーム画面追加用
- `.ai/mocks/2026-10-11-register/` — 実装前のモック
